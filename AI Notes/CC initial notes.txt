## Deployment Notes

The `alt_ascl/deployment/` directory contains all files needed to deploy the Flask application to production:
- `ascl_net_app.service` - systemd service unit (install to /etc/systemd/system/)
- `nginx_ascl_production.conf` - Nginx site config (install to /etc/nginx/sites-available/)
- `redeploy.sh` - Script to sync updates from dev repo (run directly from repo)
- `my.cnf.template` - MySQL credentials template (install to /var/www/.my.cnf)
- `DEPLOYMENT.md` - Full deployment instructions for humans and AI agents

Production paths:
- App: /var/www/ascl_net_app
- Dependencies: /var/www/dm-dbcore, /var/www/ascl_core
- Logs: /var/log/ascl_v4_uvicorn.log
- Server: Uvicorn on port 5050, proxied by Nginx for ascl.bistromath.net

To redeploy after changes: `sudo /home/demitri/repositories/ASCL/alt_ascl/deployment/redeploy.sh`

• - High – clearSearchPathCallback breaks MySQL connections: the callback is registered unconditionally
    and executes SET search_path…, which MySQL doesn’t understand. On the first pooled MySQL connection the
    adapter will raise a ProgrammingError and the app never starts. Wrap the logic in a dialect check or
    catch the database-specific exception, similar to the defensive handler you already use in the shared
    core helper. source/ascl_net_app_project_home/ascl_net_app/model/DatabaseConnection.py:12
  - High – sessionmaker(..., autocommit=True) is incompatible with SQLAlchemy 2.0: SQLAlchemy 2 removed
    the autocommit parameter; with the 2.x requirement declared in the project this line raises TypeError:
    Session() got an unexpected keyword argument 'autocommit'. Use the modern unit-of-work pattern
    (sessionmaker(bind=engine, future=True) with Session.begin()/commit()), and set connection-level
    autocommit via engine.execution_options(isolation_level="AUTOCOMMIT") only where absolutely required.
    source/ascl_net_app_project_home/ascl_net_app/model/DatabaseConnection.py:76
  - High – PostgreSQL imports of ASCLModelClasses throw NameError: when the metadata cache is empty, the
    reflection branch calls dbc.metadata.reflect(..., schema=db_schema) before db_schema is defined, so the
    first import under PostgreSQL aborts. Move the db_schema assignment ahead of the reflection block (or
    inline the literal). source/ascl_core/database/ascldb/ASCLModelClasses.py:58
  - High – sessionmaker(engine, autocommit=False) still uses the removed keyword: passing the engine as
    a positional argument works, but the autocommit kwarg was dropped in SQLAlchemy 2, so this raises the
    same TypeError as above. Drop the kwarg (False is the default) and prefer sessionmaker(bind=engine,
    future=True). source/ascl_core/database/connections/Trillian2DBConnection.py:72
  - Medium – Metadata cache never refreshes: you set need_to_update_metadata_cache = True when reflection
    runs, but later check need_to_update_metadata, which stays False, so the cache file is never rewritten.
    Rename the variable in the final if (or set need_to_update_metadata = need_to_update_metadata_cache)
    so refreshed metadata persists. source/ascl_core/database/ascldb/ASCLModelClasses.py:52 and source/
    ascl_core/database/ascldb/ASCLModelClasses.py:250
  - Medium – Possible AttributeError when cache disabled: the final block calls
    dbc.metadataCache.write(...) even when metadataCache is None (the condition checks is None and then
    dereferences it). Flip the condition to if dbc.metadataCache and ... to avoid exploding in projects
    that don’t use a cache. source/ascl_core/database/ascldb/ASCLModelClasses.py:250
  - Medium – Connection URL lacks driver and quoting: the string literal mysql://{user}:{password}
    @... assumes the legacy MySQLdb driver and breaks if credentials contain special characters. Prefer
    SQLAlchemy’s URL helpers (sqlalchemy.engine.URL.create) to pick the correct driver (mysql+pymysql) and
    percent-encode secrets. source/ascl_core/database/connections/Trillian2DBConnection.py:61
