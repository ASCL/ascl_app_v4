About ASCL.net

What is ASCL?

The Astrophysics Source Code Library (ASCL) is a free online registry for source code of interest to astronomers and astrophysicists. It lists codes that have been used in research that has appeared in, or been submitted to, peer-reviewed publications.

Citing Codes

Each code entry in the ASCL is assigned a unique identifier in the form ascl:YYMM.NNN, where:

  • YY = Year (two digits)
  • MM = Month (two digits)
  • NNN = Sequential number for that month

This identifier makes codes citable and discoverable, just like research papers.

Indexing

ASCL entries are indexed by the SAO/NASA Astrophysics Data System (ADS), making them discoverable alongside traditional research literature. This integration helps researchers find and cite the software they use.

Mission

The ASCL's mission is to:

  • Improve the transparency and reproducibility of astrophysics research
  • Provide proper credit to software authors
  • Enable discovery of research software
  • Promote best practices in scientific software development

Submitting Codes

If you have developed astrophysics source code that has been used in published research, we encourage you to submit it to the ASCL. Visit the submission page for more information.

Contact

For questions or more information about ASCL.net, please visit our website or follow us on social media.
